iLogic Suppress Feature: Show & Hide
Components Based on Parameters

Suppressing and unsuppressing features and components is one of the most powerful techniques in iLogic. It lets you build a single Autodesk Inventor model that can represent dozens of product variants — simply by toggling which features are active based on your parameters.

What Does Suppress Mean in iLogic?

In Autodesk Inventor, suppressing a feature removes it from the model rebuild — it's as if that feature doesn't exist. The feature is still in the browser tree but shown greyed out. When you unsuppress it, the feature rebuilds and appears again.

iLogic can suppress and unsuppress features automatically based on parameter values. This is how engineers build configurable product models — one file, many variants.

💡 Example: A skid frame model has an optional drip tray. A checkbox parameter IncludeDripTray controls whether the tray's sketch, extrusion, and holes are suppressed or active — all from a single iLogic rule.

Suppress a Part Feature

To suppress or unsuppress a feature in a part file, use the Feature.IsActive property:

' Suppress a feature called "DripTrayExtrusion" Feature.IsActive("DripTrayExtrusion") = False ' suppresses it Feature.IsActive("DripTrayExtrusion") = True ' unsuppresses it ' Control based on a parameter If Parameter("IncludeDripTray") = "Yes" Then Feature.IsActive("DripTrayExtrusion") = True Feature.IsActive("DripTrayHoles") = True Feature.IsActive("DripTrayGussets") = True Else Feature.IsActive("DripTrayExtrusion") = False Feature.IsActive("DripTrayHoles") = False Feature.IsActive("DripTrayGussets") = False End If

Suppress a Component in an Assembly

In an assembly file, use Component.IsActive to suppress entire parts or sub-assemblies:

' Suppress a component by its occurrence name in the assembly browser Component.IsActive("LiftingLug:1") = False ' suppress Component.IsActive("LiftingLug:1") = True ' unsuppress ' Practical example: include lifting lugs only for heavy loads Dim loadKg As Double = Parameter("TotalLoadKg") If loadKg > 5000 Then Component.IsActive("LiftingLug:1") = True Component.IsActive("LiftingLug:2") = True Component.IsActive("LiftingLug:3") = True Component.IsActive("LiftingLug:4") = True Else Component.IsActive("LiftingLug:1") = False Component.IsActive("LiftingLug:2") = False Component.IsActive("LiftingLug:3") = False Component.IsActive("LiftingLug:4") = False End If

💡 Tip: The component name (LiftingLug:1) must match exactly what appears in the assembly browser, including the occurrence number after the colon.

Suppress vs. Visibility — What's the Difference?

PropertySuppress (IsActive = False)Visibility (Visible = False)
Appears in BOMNo — removed from BOMYes — still in BOM
Appears in massNo — excluded from massYes — included in mass
Interference checkNot includedNot included
Drawing viewsNot shownNot shown
Best forOptional features/variantsReference geometry, construction only

Use suppress for product variants. If a drip tray is not included in this order, suppress it — it won't appear in the BOM or mass calculation. Visibility changes only affect display.

Managing Multiple Product Variants

When a product has many optional features, organise your suppression rule using a Select Case block for clarity:

' Product variant selection — controls which optional features are active Dim variant As String = Parameter("ProductVariant") Select Case variant Case "Standard" Component.IsActive("DripTray:1") = False Component.IsActive("AccessPlatform:1") = False Component.IsActive("FireSupression:1") = False Case "Offshore" Component.IsActive("DripTray:1") = True Component.IsActive("AccessPlatform:1") = True Component.IsActive("FireSupression:1") = False Case "ATEX" Component.IsActive("DripTray:1") = True Component.IsActive("AccessPlatform:1") = True Component.IsActive("FireSupression:1") = True End Select

Real-World Example: Optional Add-ons Rule

Here's a complete iLogic rule for a pump skid with multiple optional add-ons, controlled from an iLogic Form:

' Read selections from form checkboxes (stored as "Yes"/"No" text parameters) Dim hasDripTray As Boolean = (Parameter("IncludeDripTray") = "Yes") Dim hasLiftingLugs As Boolean = (Parameter("IncludeLiftingLugs") = "Yes") Dim hasAccessPlatform As Boolean = (Parameter("IncludeAccessPlatform") = "Yes") Dim hasGrating As Boolean = (Parameter("IncludeGrating") = "Yes") ' Apply suppressions based on selections Component.IsActive("DripTray:1") = hasDripTray Component.IsActive("LiftingLug:1") = hasLiftingLugs Component.IsActive("LiftingLug:2") = hasLiftingLugs Component.IsActive("LiftingLug:3") = hasLiftingLugs Component.IsActive("LiftingLug:4") = hasLiftingLugs Component.IsActive("AccessPlatform:1") = hasAccessPlatform Component.IsActive("Grating:1") = hasGrating Component.IsActive("Grating:2") = hasGrating

Common Mistakes

  • Wrong occurrence name — Use the exact name from the browser tree including the :1 suffix. If you renamed an occurrence, use the renamed version.
  • Suppressing a feature that drives others — If a suppressed sketch is referenced by later features, those features will also fail. Plan your feature tree order carefully.
  • Using Visible instead of IsActive for BOM control — Hidden components still appear in the BOM. If the variant shouldn't be in the BOM, suppress it.
  • Forgetting to update the drawing — After suppressing components, your drawing views may need updating. Combine with drawing automation for a fully automated workflow.
