What is a BOM in Autodesk Inventor?

A Bill of Materials (BOM) is a structured list of all components in your assembly — part numbers, descriptions, quantities, materials, and weights. In Inventor, the BOM is driven by the assembly structure and the iProperties of each component.

Every time you change your design — add a component, change a quantity, update a part number — your BOM needs to be regenerated. With iLogic, this happens automatically.

Two Approaches to BOM Export

There are two ways to get BOM data out of Inventor:

  • Built-in BOM export — Inventor's native BOM export tool. Simple, no code needed, but limited formatting options.
  • iLogic BOM export — Full control. Loop through components with code, pick exactly which data to export, format it however you need, and trigger it automatically.

Method 1: Built-In BOM Export (No Code)

For a quick BOM export without any iLogic code:

1

Open your assembly file in Autodesk Inventor.

2

Go to Manage tab → BOM (Bill of Materials). The BOM editor opens showing all components.

3

Click Export at the top of the BOM panel. Choose Excel (.xlsx) as the format and select your output location.

4

Click OK. Inventor exports the BOM table to Excel with all visible columns.

💡 This method works well for one-off exports. For automatic, repeatable BOM generation on every save, use the iLogic method below.

Method 2: iLogic BOM Export to Excel

With iLogic, you can export the BOM to Excel with a single button click — or automatically on every model save. Here's the foundation:

' iLogic BOM export to Excel ' Run from an assembly file (.iam) Dim oAsm As AssemblyDocument = ThisDoc.Document Dim oBOM As BOM = oAsm.ComponentDefinition.BOM ' Enable structured BOM view oBOM.StructuredViewEnabled = True oBOM.StructuredViewFirstLevelOnly = False ' Set the output Excel file path Dim outputPath As String = System.IO.Path.ChangeExtension(oAsm.FullFileName, "_BOM.xlsx") ' Export using Inventor's BOM export method Dim oExporter As BOMExporter = oBOM.Export oExporter.ExportStructuredBOM(outputPath, BOMExportFormatEnum.kExcel) MsgBox("BOM exported: " & outputPath)

Loop Through All Components

For full control over what gets exported, loop through the assembly components directly:

' Loop through all components and collect BOM data Dim oAsm As AssemblyDocument = ThisDoc.Document Dim oCompDef As AssemblyComponentDefinition = oAsm.ComponentDefinition ' Create Excel instance Dim oExcel As Excel.Application = New Excel.Application Dim oWB As Excel.Workbook = oExcel.Workbooks.Add Dim oWS As Excel.Worksheet = oWB.Sheets(1) ' Write header row oWS.Cells(1,1).Value = "Item" oWS.Cells(1,2).Value = "Part Number" oWS.Cells(1,3).Value = "Description" oWS.Cells(1,4).Value = "Quantity" oWS.Cells(1,5).Value = "Material" Dim row As Integer = 2 Dim item As Integer = 1 ' Loop through each unique component occurrence For Each oOccurrence As ComponentOccurrence In oCompDef.Occurrences If oOccurrence.Suppressed = False Then Dim refDoc As String = oOccurrence.ReferencedDocumentDescriptor.FullDocumentName oWS.Cells(row,1).Value = item oWS.Cells(row,2).Value = iProperties.Value(refDoc, "Project", "Part Number") oWS.Cells(row,3).Value = iProperties.Value(refDoc, "Summary", "Description") oWS.Cells(row,4).Value = 1 ' Update with actual quantity logic oWS.Cells(row,5).Value = iProperties.Value(refDoc, "Physical", "Material") row += 1 item += 1 End If Next ' Save and close Excel Dim outputPath As String = System.IO.Path.ChangeExtension(oAsm.FullFileName, "_BOM.xlsx") oWB.SaveAs(outputPath) oWB.Close() oExcel.Quit() MsgBox("BOM exported to: " & outputPath)

Format the Excel Output

You can apply Excel formatting directly from iLogic to make the BOM professional:

' Format the header row Dim headerRange As Excel.Range = oWS.Range("A1:E1") headerRange.Font.Bold = True headerRange.Interior.Color = RGB(0, 70, 127) ' Dark blue background headerRange.Font.Color = RGB(255, 255, 255) ' White text ' Auto-fit column widths oWS.Columns.AutoFit() ' Add borders to data range Dim dataRange As Excel.Range = oWS.Range("A1:E" & (row-1)) dataRange.Borders.LineStyle = Excel.XlLineStyle.xlContinuous

Auto-Export BOM on Save

Set the BOM export rule to trigger On Save in the iLogic rule settings. Every time the assembly is saved, a fresh BOM Excel file is automatically generated — no manual steps needed.

⚠️ Excel must be installed on the same machine as Inventor for the Excel automation approach to work. If Excel is not available, use Inventor's native BOM export method instead.

Common Mistakes

  • Suppressed components appearing in BOM — Always check oOccurrence.Suppressed and skip suppressed parts. See iLogic Suppress Features.
  • Missing iProperties — If part numbers or descriptions are blank, the BOM cells will be empty. Make sure all components have iProperties filled in. Use iLogic iProperties to auto-fill them.
  • Duplicate rows for multi-instance parts — Each occurrence generates its own row. Add logic to group occurrences of the same part and sum quantities.
  • Excel file locked open — If Excel is already open with the BOM file, the export will fail. Always close the file before running the export rule.
