iLogic Tutorial for Beginners:
Write Your First Automation Rule

Never written a line of iLogic code before? This tutorial walks you through everything from scratch — opening the iLogic editor, understanding the basics, and writing a real rule that changes your Autodesk Inventor model. No coding experience needed.

What is iLogic?

iLogic is Autodesk Inventor's built-in automation tool. It lets you write rules — small programs — that automatically control your 3D model. When a parameter changes, a rule can fire and automatically update dimensions, suppress features, fill in iProperties, or even export a PDF.

You write iLogic rules using a simple language called VBA (Visual Basic for Applications) — but you don't need to know VBA to get started. iLogic has a helper panel that inserts the code for you. You just need to understand the logic.

✅ Good news: If you can write an IF statement in Excel, you can write an iLogic rule. The thinking is identical — iLogic just applies it to a 3D model instead of a spreadsheet.

Before You Start

You need:

  • Autodesk Inventor installed (any version from 2018 onwards works fine)
  • A simple part file open — create a box with a Length parameter, or use any existing part
  • At least one named parameter in your model (we'll use Length as an example)
!

Create a named parameter first. Go to Manage → Parameters. Find your dimension parameter (e.g. d0) and rename it to Length. This is the parameter your rule will control.

Step 1: Open the iLogic Editor

1

Go to the Manage tab in the Inventor ribbon at the top of the screen.

2

Click iLogic in the Manage tab. A dropdown appears with options: iLogic Browser, Add Rule, Edit Rule.

3

Click iLogic Browser. A panel opens on the left side of your screen. You'll see two tabs: Rules and Forms. We'll work in the Rules tab.

💡 Shortcut: You can also right-click in the iLogic Browser and choose "Add Rule" to jump straight to creating a rule.

Step 2: Create Your First Rule

1

In the iLogic Browser, right-click in the empty Rules area and select "Add Rule".

2

Name your rule something meaningful — for example, SetLength. Click OK.

3

The rule editor opens. You'll see a large white text area on the left (where you write code) and a helper panel on the right (showing available parameters and functions).

Step 3: Write the Rule Code

In the rule editor, type this code exactly:

' My first iLogic rule ' This sets the Length parameter to 300mm Parameter("Length") = 300

That's it — your first iLogic rule. It reads as: "Set the model parameter called Length to the value 300."

💡 Helper shortcut: Instead of typing Parameter("Length"), find Length in the right-hand parameter panel and double-click it. The code is inserted automatically with the correct syntax.

Step 4: Run the Rule

1

Click the green Run button (▶) at the top of the rule editor. Or press F5.

2

Watch your model update. If your Length parameter was 200, it should now change to 300 — and the model geometry updates automatically.

3

Congratulations — you just ran your first iLogic rule. You wrote code that changed a 3D model.

✅ If it worked: Your model dimension changed. Now let's make the rule smarter by adding a condition.

⚠️ If you get an error: Check that the parameter name matches exactly — including capital letters. Length and length are different. See common iLogic errors for help.

Step 5: Add a Condition (If/Then)

Rules become powerful when they make decisions. Here's a rule that sets a different wall thickness based on a size category:

' Read the Size parameter (e.g. "Small", "Medium", "Large") Dim size As String = Parameter("Size") ' Set dimensions based on the selected size If size = "Small" Then Parameter("Length") = 200 Parameter("WallThickness") = 6 ElseIf size = "Medium" Then Parameter("Length") = 350 Parameter("WallThickness") = 8 ElseIf size = "Large" Then Parameter("Length") = 500 Parameter("WallThickness") = 12 End If

Now when an engineer changes the Size parameter to "Large", the rule fires and automatically sets the correct Length and WallThickness. One selection — multiple parameters updated.

Step 6: Set a Trigger

Right now, your rule only runs when you manually press Run. To make it fire automatically when a parameter changes:

1

In the iLogic Browser, right-click your rule and select "Edit Rule Triggers".

2

Choose a trigger type:
• Parameter Change — rule fires when a specific parameter changes
• On Open — rule fires when the file is opened
• On Save — rule fires when the file is saved
• On Change — rule fires whenever any parameter changes

3

Select "Parameter Change" and choose the Size parameter. Now every time an engineer changes the Size, your rule runs automatically.

💡 Best practice for beginners: Start with manual triggers (run button) while developing your rule. Add automatic triggers only once the rule is tested and working correctly.
